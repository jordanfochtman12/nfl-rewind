# Expansion events

- 1967: New Orleans Saints, NFL allocation draft, Tom Fears
- 1968: Cincinnati Bengals, AFL allocation draft, Paul Brown
- 1970: AFL/NFL merger; labels become AFC/NFC
- 1976: Tampa Bay Buccaneers and Seattle Seahawks; McKay/Patera
- 1995: Carolina Panthers and Jacksonville Jaguars
- 1996: Cleveland deactivates; Baltimore Ravens begin
- 1999: Cleveland Browns return as a distinct expansion club
- 2002: Houston Texans; 32-team alignment and Seattle to NFC West

Expansion code must move real players from active rosters, assign the historical coach, fill remaining positions with fully-rated players, and update the schedule and playoff field during the same season week.
